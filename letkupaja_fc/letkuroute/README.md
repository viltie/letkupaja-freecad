# letkuroute

Routing and dimension library of the Letkupaja workbench: hose and fitting dimensions, cut length and overall length,
centreline routing with the minimum bend radius, orientation (twist) between angled fittings and Letkukone order
links. Pure Python (3.10+), no dependencies. It is Letkupaja's own code, shared with Letkupaja's other CAD add-ons,
and part of this add-on under the same licence (LGPL-2.1-or-later, see `../../LICENSE`). It is not published on PyPI.

The dimension data `data/geometry.json` is not covered by the LGPL: see `../../LICENSE-Data`.
